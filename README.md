A single-page client-side web app for normalizing straight quotation marks and apostrophes to their typographically correct curly (Unicode) equivalents. Users paste arbitrary plain text into an input field; the app applies a positional heuristic — inspecting the character preceding each quote mark to determine opening versus closing orientation — and renders the converted output in a second field, from which it can be copied via the Clipboard API. All processing occurs client-side in vanilla JavaScript with no external dependencies, network requests, or persistent storage. Known limitation: word-initial elisions ('tis, 'em, '90s) are misclassified as opening quotes, since the heuristic cannot distinguish an elided apostrophe from a genuine open-quote context using only the preceding character.
